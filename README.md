## Projet principal

### [mijn-website](https://github.com/klark1152/mijn-website)

Site multipage développé en HTML, CSS et JavaScript, pensé comme une vitrine professionnelle pour des services de création web, de sécurité numérique et d'assistance informatique.

Ce projet démontre notamment :

- une interface responsive et accessible ;
- un diagnostic de sécurité exécuté localement ;
- un parcours guidé de demande de rendez-vous ;
- des contrôles automatiques de qualité ;
- une approche transparente de la sécurité et des données personnelles.

## Ma façon de travailler

1. comprendre le besoin et définir un périmètre clair ;
2. construire une solution simple à maintenir ;
3. vérifier l'accessibilité, la sécurité et le comportement mobile ;
4. documenter les choix et améliorer le projet grâce aux retours.

> Les interventions de sécurité sont réalisées uniquement dans un cadre autorisé, documenté et responsable.
